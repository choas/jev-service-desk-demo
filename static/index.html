Jev Service Desk

A service bot that never makes up text. It only decides.

How it works

  1. Jev reads your message and answers a few fixed questions with probabilities.
  2. If it is sure, plain code looks up the data and picks a prepared reply.
  3. If it is not sure, the bot asks you instead of guessing.
